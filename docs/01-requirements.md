# 01 需求规格 · 合璧字幕 HebiSubs

> 文档版本：v0.2（草案，P3 定稿）｜ 建立：2026-10-15 ｜ v0.2：2026-10-16 C11 P1 复盘修订（F1.4、F2.1、F4.2、F4.3、F5.1–F5.3、F6.8、F8.2、开放问题 6–7）
> 标记：✅ 已确认 ｜ 🔶 草案待确认 ｜ ❓ 开放问题

## 1. 背景

- MP（V3）+ Jellyfin 观影；外国电影需要中英（简中+外语）双语字幕。
- 资源常只带中字或只带英字，手动找字幕、放进媒体文件夹很麻烦。
- 平时主要在 SubHD 找字幕（中英特效字幕丰富）。
- 试用海拉鲁字幕大师发现：SubHD 结果**不按下载量排序**、**不显示制作组**、难分好坏；**整包压缩包无法处理**。

## 2. 功能需求

### F1 触发方式
- ✅ F1.1 新资源整理入库后自动处理（MP 整理完成事件）
- ✅ F1.2 扫描历史媒体库，为缺字幕影片补全（分批、限速、可暂停）
- 🔶 F1.3 手动对单部影片触发搜索，并可人工挑选候选
- 🔶 F1.4 跳过条件 =「已满足落盘目标」：同目录已有 ≥2 份合格的简中+外语双语外挂字幕（华语片见 F6.8）；只有简中单语或繁体时**继续处理**；语言判定通过样本测试之前，判不准的一律视为「不满足」（宁可多找，不漏）（P1 复盘：海拉鲁「已有任意中文就跳过」会漏）

### F2 影片识别
- 🔶 F2.1 身份来源分入口：**自动触发**以整理完成事件的 `mediainfo` 为主（已带 TMDB ID；事件发出时 NFO 可能尚未刮削生成，待 P5 实测）；**历史库扫描**读 MP 生成的 `movie.nfo`；两者统一成同一个任务输入。IMDb ID、原名、中文名、年份都纳入身份
- 🔶 F2.2 读取视频文件名中的片源信息（压制组、WEB-DL/BluRay、分辨率）用于版本匹配

### F3 字幕源
- ✅ F3.1 ASSRT：官方 API（Token）
- ✅ F3.2 SubHD：网页接口；**不破解验证码**，触发时转人工
- 🔶 F3.3 字幕源可插拔，统一接口，后续可加源

### F4 候选展示与选择（针对海拉鲁的痛点）
- ✅ F4.1 候选可按 **下载量 / 评分 / 上传时间** 排序
- ✅ F4.2 显示 **制作组/发布人、来源类型**（官方 / 原创翻译 / 转载精修 / 机翻 / AI 校对）、语言、格式、片源版本
  - 质量字段（下载量 / 评分 / 上传时间）拿不到时记为「无」，与 0 区分；保留每条候选在源站结果页里的原始位置（D014）
- 🔶 F4.3 自动打分：语言（必须含简中+外语）> 片源版本匹配 > 来源类型（官方/原创优先，机翻降权）> 下载量/评分 > 格式偏好
  - 排序只在核心层做一次，自动挑选与界面默认顺序一致；界面上的「按下载量/评分/时间排序」只改显示顺序；下载量跨源比较前先在源内归一化；字幕源优先级最多是弱权重；打平时退回源站原始顺序，不按标题排序（D014）
- 🔶 F4.4 自动选出 Top 2；手动模式下可改选

### F5 下载与解包
- ✅ F5.1 支持 ZIP / RAR / 7z 压缩包，**面向 Windows 原生运行**：用魔数判断格式；zip 用标准库；rar/7z 用外部工具，按候选清单探测并实际运行确认（方向见 D015，P2 验证）；依赖状态在界面展示
- ✅ F5.2 解包后按语言、格式、文件名自动挑出目标字幕；无法判断时转人工挑选
  - 保留包内目录结构（目录名里的语言、集数信息参与挑选）；内层压缩包递归解开（深度 ≤2，共用资源上限）；zip 内无 UTF-8 标志的文件名做编码回转（GBK/Big5）；解包资源上限防护（成员数、大小、路径穿越）
- ✅ F5.3 **所有输出字幕统一写成 UTF-8**（GBK/Big5 先识别再转码）；🔶 清除 SRT 中的 HTML 标签、繁转简（可选）

### F6 落盘规范
- ✅ F6.1 每部影片在**视频同目录**放 **2 份最佳双语字幕（简体中文 + 外语）**，Jellyfin 可直接识别、可在播放时选择
- ✅ F6.2 **原字幕压缩包也保存**
- ✅ F6.3 没有现成双语时，用「简中单语 + 外语单语」**合成**双语
- ✅ F6.4 保留扩展：仅有外文字幕时，AI 翻译成中文再合成（P7）
- 🔶 F6.5 不覆盖、不删除已有字幕；视频文件与下载目录一律不碰
- ❓ F6.6 两份双语的文件命名方案（需 P2 实测 Jellyfin 对外挂字幕标题/语言的识别规则）
- ❓ F6.7 原始压缩包存放位置：A 影片目录下子文件夹（需确认 Jellyfin 不会误读）／B 媒体库之外的集中存档目录（按影片目录镜像）
- ✅ F6.8 **华语片也处理**，只需简中字幕，不要求双语（D017）；华语片的判定依据（TMDb 原始语言 / 地区）与落盘份数 🔶 P3 定

### F7 校验
- 🔶 F7.1 语言检测（确认真含简中 + 外语）
- 🔶 F7.2 时长覆盖检查（字幕结束时间与视频时长）
- 🔶 F7.3 可选对轴（P5 以后）

### F8 运维与兜底
- 🔶 F8.1 每个视频一条状态记录（待处理/完成/失败/待人工），幂等可重试
- 🔶 F8.2 每个字幕源独立限速 + 熔断（连续失败自动停用并通知）；限速在 HTTP 层**按请求计数**（搜索、详情、下载都算），不按「一次搜索调用」计数
- 🔶 F8.3 Telegram 通知；人工投喂目录（浏览器手动下载的字幕放进去，插件自动接手）
- 🔶 F8.4 刷新 Jellyfin 对应条目

## 3. 非功能需求

| 项 | 要求 |
|---|---|
| 安全 | 只新增文件；开发期只写测试目录；真实库接入前备份 |
| 合规 | 遵守站点限速与条款；不破解验证码；ASSRT 注明来源 |
| 限额 | ASSRT 初始 20 次/分钟（按 token 与 IP 共享计算）；SubHD 低频，历史库批量扫描不走 SubHD（🔶） |
| 可维护 | Provider 可插拔；核心逻辑与 MP 接口层分离，便于跟随 MP 版本迁移 |
| 可学习 | 中文注释；文件开头写用途与用法；命名详细；显示时刻用 12 小时制标 AM/PM |
