> 文档版本：v0.1 ｜ 建立：2026-10-15 ｜ 维护规则：按需修改，不整篇重写

## 1. 项目一句话

为 MoviePilot V3 写一个第三方插件：从 **SubHD + ASSRT** 获取字幕，为每部影片在媒体文件夹落盘 **2 份最佳「简中+外语」双语字幕**，原始字幕包另行存档；没有现成双语时自动合成；Jellyfin 直接识别并可选择播放。

- 中文名：**合璧字幕**（取“中西合璧”，中文与外文字幕合成一体）
- 英文名 / 插件类名：**HebiSubs** ／ 插件目录 `hebisubs`（V3 目录规则以官方 V3 开发指南为准）
- 仓库：`hebi-subs`（GitHub 私有仓库）｜本地路径：`D:\code\hebi-subs`
- 参考项目：海拉鲁字幕大师（ifsherlock/MoviePilot-Plugins），只读克隆在项目内 `_reference\hailulu\`（已 gitignore）

## 4. 对话地图（claude.ai 项目内）

命名规则：`<编号>-<主题>`，置于项目内。一个对话只做一件事；对话变长或主题完成 → 写交接卡 → 开新对话。

| 编号 | 对话 | 做什么 | 何时开 / 关 |
|---|---|---|---|
| C00 | 立项（本对话） | 定方案、名字、文档体系 | 已完成，之后不再续写 |
| C01 | 总控台 | 阶段评审、关键决策、进度更新、文档同步 | 常驻；过长时开 C01b |
| C1x | 阶段对话 | 每个阶段一个：P1 研读复盘、P2 接口实测、P3 设计、P4… | 阶段开始时开，阶段验收后关 |
| C90 | 原理答疑 | 随时问原理；阶段结束用 `/principle-notes` 出 Obsidian 笔记 | 常驻 |

**Claude Code 会话**（VS Code 内）：一个任务一个会话，起名与任务卡一致（如 `P2-assrt-probe`），做完提交即结束。

## 8. 协作规则

1. 复杂任务先出计划，确认后执行；一次只推进一步。
2. 改代码只说明改动部分；每处关键改动讲原理。
3. 同一操作连续报错 2 次、卡住或预计大量消耗额度 → 立刻停下说明原因。
4. 开发期只写测试目录；接入真实媒体库前先备份。
5. 不确定的信息标“不确定”；版本、接口等时效信息联网核实并附来源。
